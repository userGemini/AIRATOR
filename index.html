AQUASCOPE

Monitoring kualitas air real-time · HiveMQ MQTT

Mode Simulasi

Lokasi Node

Lat —, Lng — sumber: default
Dibuat untuk koneksi ke broker HiveMQ via MQTT-over-WebSocket. Mode simulasi aktif secara default agar tampilan langsung hidup — sambungkan broker asli lewat panel Pengaturan.

Pengaturan Broker

Koneksi HiveMQ

Broker publik broker.hivemq.com tidak butuh autentikasi tapi bersifat terbuka untuk semua orang — pakai HiveMQ Cloud + username/password untuk data produksi.

Pemetaan Topik

Payload contoh: {"ph":7.2,"turbidity":3.1,"tds":420,"salinity":0.3,"do":6.8,"temp":27.5,"lat":-7.2575,"lng":112.7521}

Payload: -7.2575,112.7521 atau JSON {"lat":-7.2575,"lng":112.7521}

Uji cepat dari command line (port MQTT biasa, bukan WebSocket):
mosquitto_pub -h broker.hivemq.com -p 1883 -t aquascope/sensors/ph -m "7.2"
